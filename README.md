# TK2000 an MPF-II Computer Clone

This repository documents the complete development of a functional
MPF-II Computer Clone Clone, following the schematics, 
layout, and design principles.

The project is organized into multiple hardware-specific
sub-repositories. Each one contains schematics, PCB layouts,
documentation, and photos related to a specific module of the system.

The goal is to faithfully reproduce a MPF-II Computer Clone
architecture while documenting the full hardware development process.

1) Microdigital-TK2000 an MPF-II Clone:  https://github.com/frubem/Microdigital-TK2000
2) TK2000 Build Notes: https://github.com/frubem/TK2000_Build_Notes
3) TK2000 Keyboard: https://github.com/frubem/TK2KB
4) TK2000 Bus Extender: https://github.com/frubem/TK2000_bus_extender 
6) TK2000 Disk Interface: https://github.com/frubem/TK2000_DiskInterface_REDUX
7) TK2000 Fully Addressable Simple Twin Interface Digital I/O: https://github.com/frubem/TK2000_FASTIDIO
8) TK2000 VDP Board: https://github.com/frubem/TK2000_VDPboard
9) TK2000 VGA: https://github.com/frubem/TK2000-VGA
